# 火柴（Huochai）离线单文件版

面向 Windows 的本地文件搜索工具，基于火柴 `2.1.0.11` 精简和重打包。保留文件检索、便签、快捷键和托盘设置，移除聊天、登录、在线升级等组件。

## 项目预览

- **本地检索**：按文件名搜索磁盘文件，支持中文、多关键词和扩展名条件。
- **快捷唤起**：双击 `Ctrl` 打开或隐藏搜索框。
- **单文件分发**：运行后在 EXE 同级目录保存程序、配置和索引。
- **索引复用**：保存索引缓存，后续启动读取缓存并更新文件变化。

当前版本：`2026.10.04.1` · Everything `1.5.0.1423b` x64（beta）· Windows 10/11 x64

## 使用

1. 下载 [火柴单文件版.exe](火柴单文件版.exe)，放入有写入权限的本地目录并运行。
2. 首次启动需要建立索引；安装索引服务时可能需要管理员授权。
3. 双击 `Ctrl`，输入文件名搜索。通过托盘菜单退出程序。

配置、便签和索引保存在同级 `HuoChatOffline-v1-single` 目录。升级前先退出并备份，替换 EXE 时保留数据目录；移动时将两者一起移动。

## 本版更新

- 修复回收站等系统位置无法打开的问题：改为按 shell 命名空间项打开，不再退回到「选择应用以打开」。
- 收紧本地守卫：带引号的网络共享路径此前可绕过拦截，动态获取地址也不再绕过进程守卫。
- 修复启动与退出异常：上次残留的搜索引擎不再导致程序无法启动，等待主程序退出超时不再误报异常退出。
- 引擎停止与删除服务改分段申请权限，标准账户也能正常停止本目录的服务。
